# Project-1A-Securitisation-Risk-Analytics

This project focuses on securitisation risk analytics, analyzing auto loan securitisation data to understand risks and performance.

## Project Structure

- `data/raw/`: Raw datasets
- `data/cleaned/`: Processed and cleaned datasets
- `notebooks/`: Jupyter notebooks for analysis
- `powerbi/`: Power BI reports and dashboards
- `docs/`: Documentation
- `screenshots/`: Screenshots of visualizations

## Datasets

- auto_loan_securitisation_data.csv
- static_pool_vintage_data.csv
- dynamic_loss_monthly.csv
- dpd_snapshot_history.csv

## Getting Started

1. Clone this repository
2. Place raw datasets in `data/raw/`
3. Run notebooks in `notebooks/` for analysis

## Tools Used

- Python
- Jupyter Notebook
- Power BI
